# Sistema Web ONG

Proyecto desarrollado en PHP y MySQL para la gestión de:

- Proyectos
- Donantes
- Donaciones

## Tecnologías
- HTML
- JavaScript
- PHP
- MySQL (XAMPP)

## Funcionalidades
- Registro de proyectos
- Registro de donantes
- Registro de donaciones
- Consulta de datos
- Uso de sesiones
